# Riddhi AI Assistant

A voice-first AI assistant built with React, TypeScript, Vite, Tailwind CSS, and a Gemini Live-style architecture.

## Features
- Voice-first futuristic dark UI
- Hindi / English / Hinglish conversation mode
- Real-time mic audio streaming architecture via Web Audio API
- Gemini Live session integration-ready wrapper
- Browser action tools like open/refresh/scroll
- Camera vision panel and multi-agent roster
- Permissions gate and settings panel
- Personality layer for a sassy, witty, emotionally aware assistant

## Setup
1. Install dependencies:
   npm install
2. Create a `.env` file and add your API key:
   VITE_GEMINI_API_KEY=your_key_here
3. Run the app:
   npm run dev

## Build
npm run build

## Notes
- Browser microphone and camera permissions are required for live interaction.
- The app is intentionally architecture-first and ready for real Gemini Live integration when a working API key is provided.
